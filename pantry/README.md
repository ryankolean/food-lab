# Pantry

Seasoning blends, salts and other keep-on-the-shelf builds. These are ratio problems more
than recipes: the components are usually obvious, and the work is deciding how much of each.

Test blends side by side on the same batch of whatever you are seasoning — fries are the
usual control.

Tracked in Jira: [HOUSE-53](https://ryan-kolean.atlassian.net/browse/HOUSE-53)
