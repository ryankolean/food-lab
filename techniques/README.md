# Techniques

Methods rather than recipes: things that change how a component gets made, or how it gets
stored. Anything here should be testable on its own, with a clear before and after.

These matter most to the freezer sauce library — see [`sauces/`](../sauces/).

Tracked in Jira: [HOUSE-53](https://ryan-kolean.atlassian.net/browse/HOUSE-53)

## For each recipe, record

- The claim being tested, stated plainly
- The control: the normal method, done at the same time with the same ingredients
- What actually changed — time, texture, flavour — and by how much
- Whether it is worth the extra step
