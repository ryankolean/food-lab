# Gribiche Blender Sauce

> **Stub.** Not written or tested yet.

## Starting notes

- Pitched as an aioli replacement — a gribiche built in an immersion blender in about a minute.
- Uses shown in the post: fries, fried chicken sandwiches, roasted vegetables, grain bowls, crudités, hard boiled eggs, chicken salad, boiled potatoes, salmon, cold meats.
- The charred garlic is the part worth testing first — it is what separates this from a plain sauce gribiche.
- Egg emulsion: does not freeze. Cold sauce, not part of the HOUSE-39 freezer library.
- Ledger entry: [`prospects/instagram.md`](../../prospects/instagram.md) — entry 5.

## Ingredients

| Amount | Ingredient | Notes |

|  | Garlic | charred |
|  | Dijon mustard |  |
|  | Neutral oil | added last, in a stream |
|  | Lemon | juice, to finish |

## Method

1. Put everything except the oil into a tall narrow container.
2. Blitz with an immersion blender, adding the oil in a stream, until thick and pale green.
3. Finish with lemon juice and season.
