# Everything Sauce

> **Stub.** Not written or tested yet.

## Starting notes

- A bright green blender sauce that goes into a squeeze bottle and onto everything. Shown on tacos.
- **No quantities, and no recipe in the comments either** — the caption is two words and a comment-gated prompt, and the creator never posted a recipe underneath. Everything below is from the video.
- Commenters make a fair point: this is close to a green chutney loosened with yogurt and mayo. Worth reverse-engineering the ratio from that direction rather than treating it as a novel build — start from a chutney (herbs, chilli, lime, salt) and decide how much dairy to carry it.
- Mint is in it. One commenter flags it and the frames show a second leafy green going in after the cilantro, so build for cilantro plus mint rather than cilantro alone.
- Two jalapeños went in whole, stems off, seeds in. That is the heat ceiling to calibrate against.
- Occupies the same slot as [`gribiche-blender-sauce.md`](gribiche-blender-sauce.md) and [`high-protein-ranch.md`](high-protein-ranch.md) — three different answers to the same "creamy sauce in a squeeze bottle" problem. Worth tasting side by side.
- Ledger entry: [`prospects/instagram.md`](../../prospects/instagram.md) — entry 49.

## Ingredients

| Amount | Ingredient | Notes |
| ---: | --- | --- |
|  | Mayonnaise | in first |
|  | Sour cream or thick yogurt | second scoop |
|  | Cilantro | a large bunch, stems and all |
|  | Mint or spinach | a second green, added after the cilantro |
| 2 | Jalapeños | whole, stems off |
|  | Hot sauce | a bottled one, a spoonful |
| 1 | Lime | zested and juiced |
|  | Water | a splash, to get it moving |
|  | Honey | a squeeze |
|  | Mustard | a spoonful |
|  | Salt | |

## Method

1. Add the mayonnaise and sour cream to a blender.
2. Pack in the cilantro and the second green.
3. Add the jalapeños, hot sauce, lime zest and juice, water, honey, mustard and salt.
4. Blend until bright green and pourable.
5. Decant into a squeeze bottle.
