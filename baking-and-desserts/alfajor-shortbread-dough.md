## Ingredients

| Amount | Ingredient | Notes |
| ---: | --- | --- |
| 250 g | Flour |  |
| 5 g | Baking powder |  |
| 125 g | Sugar |  |
| 1 | Egg |  |
| 2 g | Salt |  |
|  | Vanilla essence | a splash |
| 125 g | Butter | cold, cubed |

## Method

1. Cream the butter with the sugar until foamy.
2. Add the egg, then the remaining ingredients.
3. Chill 30 minutes.
4. Cut 7 cm rounds and bake about 10 minutes.
