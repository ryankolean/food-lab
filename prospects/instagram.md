# Instagram Prospects

A log of every Instagram Reel and post reviewed for the Food Lab. The
[`/ig-intake`](../.claude/skills/ig-intake/SKILL.md) skill appends to this file and checks it first, so a
post is never reviewed twice.

**Status:** `new` (reviewed, not decided yet) · `stubbed → <path>` · `skipped` · `unreadable`

**Recipe given?:** `full` (quantities shown) · `partial` · `idea only` · `link out`
